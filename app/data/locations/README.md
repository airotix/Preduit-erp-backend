Geographic data derived from country-state-city 3.2.1:
https://github.com/harpreetkhalsagtbit/country-state-city

The upstream package's GPL-3.0 license is included in LICENSE. The SQLite database
is a reproducible transformation of its country/state/city JSON assets; rebuild
using backend/scripts/build_location_data.py after installing frontend dependencies.
No coordinates or global city lists are delivered to the browser.
